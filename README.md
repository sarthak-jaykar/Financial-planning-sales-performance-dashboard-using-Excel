# Financial Planning & Sales Performance Dashboard (Excel)

## Overview
This project is an interactive Excel dashboard built using the Sample Superstore dataset. It analyzes retail sales performance and provides business insights through KPIs, Pivot Tables, Pivot Charts, and Slicers.

## Objectives
- Analyze sales and profit performance.
- Identify top-performing regions and product categories.
- Monitor monthly sales trends.
- Provide actionable business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Tables
- XLOOKUP
- SUMIFS
- COUNTIFS
- Conditional Formatting

## Dashboard KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Profit Margin

## Features
- Interactive dashboard with slicers
- Regional sales analysis
- Monthly sales trend
- Top 10 products by sales
- Category-wise profit analysis
- Segment-wise sales analysis
- Executive Summary with recommendations

## Dataset
- Sample Superstore Dataset
- 9,994 retail sales records
